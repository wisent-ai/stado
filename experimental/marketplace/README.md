# Marketplace (experimental)

GPU compute marketplace: rent and host GPU machines.

This is an experimental Stado feature, merged here from the former
`wisent-ai/compute.wisent.com` repository on 2026-08-11 with its full history.
It is not a second fleet product: it owns offers, rentals, credits and API keys,
and asks Stado to do the actual provisioning. Marketplace rental state and Stado
job state remain different things.

Nothing here is published or operated. The last word from the standalone
repository was a commit recording exactly that, and merging it changed its
status from "separate product waiting on a decision" to "Stado feature waiting
on a decision".
